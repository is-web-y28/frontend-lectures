# Лекция 08: подготовка и контрольные точки

Основной маршрут — 74 слайда, пять глав, план на 90 минут; приложения после слайда 74 необязательны. Это план репетиции, а не измеренный темп проведённого занятия. Он совпадает с таблицей в заметках к слайду маршрута.

| К отметке | Действие и результат |
| --- | --- |
| 4 минуты | Строка из поля дала ошибочное сложение; роли Vite, TypeScript и runtime-проверки разделены. |
| 22 минуты | Показаны файлы проекта, установка из lockfile, запуск локальной команды и вход HTML → main.ts. |
| 36 минут | Прочитана реальная ошибка поля count: фактическая строка, ожидаемое число; исправление прошло check. |
| 57 минут | Одна Registration связала описание полей, отсутствие значения, store и производные типы. |
| 70 минут | DOM и неизвестный JSON проверены до использования; успешная ветка Result открыла value. |
| 82 минуты | Проверены build/preview, env, адрес изображения и source map; общий сценарий дошёл до импорта. |
| 90 минут | Диагностика по слою ошибки и вопросы; переход к Vue без обещания автоматической валидации. |

До занятия выполнить `npm ci` и `npm run build:ts-examples`. В отдельных терминалах запустить `npm run dev:08`, `npm run dev:ts-examples` и при необходимости `npm run check:watch --workspace examples/08-tooling-typescript`. Подготовить редактор с `examples/08-tooling-typescript`, Console/Network/Sources и вкладку `preview`. Не тратить время объяснения типов на загрузку пакетов; установку воспроизводим на подготовленном окружении и читаем её фактический вывод.

В первой главе один раз пройти цепочку: манифест → lockfile → npm ci → npm run dev → модуль в Network. Команды добавления и удаления зависимостей объясняют изменение файлов; не нужно устанавливать все упомянутые пакеты подряд. Вспомогательные страницы режимов `sum`, `types`, `assertion`, `tooling`, `full` открывать по действиям из slide-local notes.

В блоке типов временно передать `countInput.value` в числовое поле и выполнить `npm run check:ts-examples`. Прочитать место, фактический тип и ожидаемую форму, затем вернуть преобразование и правило формы. Перенос поля и ошибка присваивания — две границы одного договора, а не повод для нескольких одинаковых циклов редактирования. Слайды с `void`, `type/interface`, `Omit`, `Pick` и `Partial` оставлять небольшими отдельными шагами: каждый отвечает на свой вопрос и не подменяет проверку входа.

В главе внешних данных оставить один ошибочный JSON, один успех и одно необоснованное `as`. На отказе коллекция неизменна; аннотация не проверила поля, это сделал валидатор. Связать уже знакомые проверки из 07 с сужением `unknown`, не вводить заново весь алгоритм регистрации. Объяснение `Result<T>` должно сохранить связь `ok` и `value`; ускорение здесь за счёт пропуска успешной ветки разрушит смысл примера.

Перед сборочным сценарием удалить все временные ошибки. Выполнить `npm run build:ts-examples`, затем `npm run preview:ts-examples`. Сравнить фактический URL SVG, публичный файл и значение env. В Sources поставить breakpoint в `handlePreviewClick`, нажать «Выполнить обработчик», прочитать аргумент и стек, продолжить. Для env явно назвать необходимость перезапуска или пересборки; не редактировать готовый dist вручную.

Общий сценарий на слайде 72: три исходные заявки → Глеб / gleb@example.com / 3 через Enter → поиск Глеба → удаление Space → очистка поиска → неверный импорт без потери коллекции → корректный импорт Даши → обычное удаление Даши. Сверить количество и фокус. Проверка импорта и действия формы используют то же хранилище. В диагностике достаточно одной новой ошибки и одного прогноза аудитории; не повторять все опыты из каждой главы.

Во время репетиции записать фактические отметки, включая команды, ожидание сборки, чтение кода и ответы вслух. При отставании сначала исключать повторные опыты с тем же результатом и необязательные настройки окружения; сохранять малые шаги новых конструкций, общий сценарий и вопросы. Если материал устойчиво не помещается, пересмотреть объём занятия до проведения, а не считать таблицу доказанным хронометражем. Отдельные приложения не использовать для завершения недообъяснённого основного маршрута.
