# План лекций по дисциплине «Web-разработка: Frontend»

|      № | Тема лекции                                   | Ключевое содержание                                                                                                                                          | Лабораторные работы          |
| -----: | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------- |
|  **1** | **Web и HTML**                                | Как устроен Web, клиент–сервер, HTTP, URL, работа браузера и загрузка страницы. Структура HTML-документа, семантика, основные элементы, формы.               | **ЛР 1: HTML**               |

|  **3** | **Верстка средствами CSS**                    | Поток документа, `display`, позиционирование элементов, Flexbox, Grid, единицы измерения.                                                                    | **ЛР 2: CSS**                |
|  **4** | **Современный CSS**                           | Адаптивность, media queries, responsive design, CSS transforms, transitions, animations, CSS variables.                                                      |                              |
|  **5** | **Организация CSS и CSS-инструменты**         | Методологии CSS, BEM, организация стилей, препроцессоры, PostCSS, CSS-фреймворки, utility-first подход.                                                      |                              |
|  **6** | **JavaScript и программирование браузера**    | Переменные, типы данных, операторы, условия, циклы, массивы, объекты. Функции. Основы DOM, события и обработчики событий.                                    | **ЛР 3: JavaScript**         |
|  **7** | **Современный JavaScript и введение в React** | Функции, области видимости, замыкания, ES Modules, destructuring, spread/rest. Назначение UI-фреймворков, декларативный подход, SPA, JSX, компоненты, props. |                              |
|  **8** | **React: состояние и взаимодействие**         | State, `useState`, события, условный рендеринг, списки, формы, базовый `useEffect`, жизненный цикл компонента.                                               | **ЛР 4: React**              |
|  **9** | **Асинхронный JavaScript и Web API**          | Event Loop, Promise, `async`/`await`, `fetch`, HTTP API, JSON, обработка ошибок.                                                                             |                              |
| **10** | **TypeScript и инструменты разработки**       | Статическая типизация, `type`, `interface`, основы generics. npm, `package.json`, зависимости, инструменты сборки, Vite, транспиляция, production build.     |                              |
| **11** | **React: композиция и управление состоянием** | Подъем состояния, controlled components, Context, `useContext`, custom hooks, композиция компонентов.                                                        | Подготовка к проекту         |
| **12** | **Архитектура React-приложения**              | Структура проекта, разделение ответственности, переиспользуемые компоненты, hooks, services, routing, организация работы с API.                              | **ЛР 5: проект**             |
| **13** | **Управление состоянием и экосистема React**  | Локальное, глобальное и серверное состояние. Context, Redux/Zustand, TanStack Query. Критерии выбора сторонних библиотек.                                    |                              |
| **14** | **Другие frontend-фреймворки**                | React в контексте современной frontend-экосистемы. Vue, Angular, Svelte и другие решения. SPA и MPA. Сравнение архитектурных подходов.                       | **ЛР 6: проект**             |
| **15** | **Next.js и full-stack React**                | Назначение Next.js. CSR, SSR и SSG, routing, Server Components, серверный и клиентский код, API/backend-возможности, deployment.                             |                              |
| **16** | **Современная frontend-разработка**           | Производительность, lazy loading, code splitting, accessibility, SEO, тестирование. Обзор современных архитектурных подходов и развития Web.                 | **ЛР 7: завершение проекта** |

## Презентации

```sh
npm install
npm run dev:01
npm run dev:02
npm run dev:03
npm run dev:04
npm run build:01
npm run build:02
npm run build:03
npm run build:04
npm run build:all
```

- `slides/01-web-html.md` — первая лекция;
- `slides/02-css-basics.md` — вторая лекция; использует тему `slidev-theme-tahta`;
- `slides/03-css-layout.md` — третья лекция; использует тему `slidev-theme-tahta`;
- `slides/04-modern-css.md` — четвёртая лекция; основной 90-минутный материал и факультативный модуль используют тему `slidev-theme-tahta`;
- `slides/public/examples/01-web-html/` — исполняемый HTML-пример для первой лекции;
- `slides/public/examples/02-css-basics/` — исполняемый HTML- и CSS-пример для второй лекции;
- `slides/public/examples/03-css-layout/` — исполняемый HTML- и CSS-пример для третьей лекции;
- `slides/public/examples/04-modern-css/` — исполняемый HTML- и CSS-пример для четвёртой лекции;
- `npm run build:all` собирает все файлы `slides/*.md` в `slides/dist/` без заметок докладчика.
