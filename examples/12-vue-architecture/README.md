# Frontend Meetup · архитектура Vue-приложения

Из корня репозитория:

```sh
npm run dev:architecture-example
npm run dev:architecture-example -- --mode history
npm run check:architecture-example
npm run build:architecture-example
```

В обычном режиме Vue Router читает маршрут после `#`. Это позволяет открывать скопированные адреса на статическом хостинге. Режим разработки `history` использует пути без `#`; для него Vite возвращает документ приложения по прямой ссылке. Сборка для слайдов использует hash-режим.

Форма создаёт локальные записи Pinia. Экран «Заявки из API» читает отдельные JSON-образцы из лекции 10 через знакомый клиент. Условия «Имитация 503» и «Медленный Frontend Meetup» задаются в обёртке для демонстраций. Ошибка 503 отмечается в журнале. Опыт с неверными полями использует настоящее чтение JSON и проверку структуры. При запуске данные Pinia и язык инициализируются заново.

`src/features/registrations` показывает организацию одного рабочего слайса по Feature-Sliced Design. В `ui` лежат форма и локальный список, в `model` — состояние, операции и логика загрузки, в `api` — клиент. Страницы и точка входа получают нужные имена через `@/features/registrations`. Этот путь ведёт к `index.ts` с явными реэкспортами.

Параметр `demo` перед `#` выбирает начальный режим: `legacy`, `routes`, `page-state`, `store`, `api`, `dependency`, `contract`, `locale`, `fallback` или `full`. В маршруте списка `?minSeats=2` после `#` включает отбор от двух мест.

- `legacy` переключает два экрана через локальный `ref` и открывает тот же адрес отдельной ссылкой.
- `dependency` показывает выбор клиента через ближайшего поставщика.
- `contract` сравнивает два парсера на том же HTTP-ответе с `items`. После смены парсера нажмите «Повторить».
- `fallback` оставляет английский словарь без ключа `minSeats`. После выбора English подпись фильтра появится на русском.
