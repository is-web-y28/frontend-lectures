# Лекция 09: Frontend Meetup на Vue

Отдельное приложение на Vue 3, TypeScript и Vite. Оно повторяет модель встроенного демо лекции: Анна занимает два места, Борис — одно. Все заявки живут в памяти; перезагрузка возвращает начальные данные. Хранение из лекции 07 здесь намеренно опущено, чтобы наблюдать связь состояния с интерфейсом.

## Запуск

Из корня репозитория (Node.js 22.18+):

```bash
npm ci
npm run dev:vue-example
```

Откройте адрес, напечатанный Vite. Для изменения адреса и порта:

```bash
npm run dev:vue-example -- --host 127.0.0.1 --port 5179
```

Проверка типов, сборка и просмотр сборки:

```bash
npm run check:vue-example
npm run build:vue-example
npm run preview:vue-example
```

Сборка находится в `examples/09-vue-reactivity/dist/`. Относительный `base` позволяет размещать её в подпапке. Приложение запускается отдельно от Slidev; исходники не зависят от компонентов презентации.

## Что читать

- `index.html` — HTML-точка входа и контейнер `#app`.
- `src/main.ts` — создание приложения и монтирование `App`.
- `src/App.vue` — тип заявки, исходное состояние, вычисления, обработчики и шаблон.
- `src/styles.css` — оформление и адаптация к узкому экрану.
- `vite.config.ts` — подключение компиляции однофайловых Vue-компонентов.

В `App.vue` сначала идут источники `ref`, затем производные `computed`, затем обработчики. В JavaScript читаем `.value`; в шаблоне Vue раскрывает верхнеуровневые `ref`. `visible` фильтрует список, `seats` считает места по полному массиву, `canSubmit` проверяет черновик. Обработчик `add` повторно проверяет данные перед записью. `v-for` использует устойчивый `id` в качестве ключа.

## Сценарий показа преподавателем

1. Нажмите «Начать заново»: две заявки, три места. Откройте блок «Состояние и вычисляемые значения».
2. Введите в имя пробелы, затем попробуйте имя «Вера» с пустым количеством и с количеством 6. Кнопка недоступна; исходный массив не меняется. Пустое числовое поле даёт строку, что видно в `countType`.
3. Исправьте черновик на «Вера, 2». Кнопка доступна, но запись ещё не создана.
4. В поиске введите «Вера»: виден пустой результат, общий итог всё ещё три.
5. Отправьте форму клавишей Enter из поля «Имя»: появится Вера, итог станет пять, черновик сбросится. Поиск сохранится.
6. Удалите Веру: пустой результат, итог три. Очистите поиск: снова видны Анна и Борис.
7. Введите «Анна»: видна одна запись, но исходных заявок две и общий итог три. Поиск не удаляет Бориса.
8. Перезагрузите страницу и проверьте возвращение начального состояния.

Перед каждым действием можно попросить аудиторию предсказать изменения. Это демонстрация преподавателя, самостоятельных заданий нет.

Для Vue Devtools запустите именно dev-сервер и установите [расширение Vue 3](https://devtools.vuejs.org/guide/browser-extension). В дереве Components выберите `App`: сопоставьте `query`, `registrations`, `visible`, `seats` и `canSubmit` с интерфейсом. Исследуйте состояние реальными контролами; встроенный раскрывающийся блок позволяет провести показ и без расширения.

Нативные `required`, `min`, `max` и `step` дополняют проверку обработчика. Недоступная кнопка сама по себе не демонстрирует нативную валидацию: её может раньше заблокировать `canSubmit`. Серверной проверки и сохранения здесь нет.

Справка: [запуск Vue-приложения](https://vuejs.org/guide/quick-start.html), [привязки полей формы](https://vuejs.org/guide/essentials/forms.html).
