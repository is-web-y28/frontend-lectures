Что собралось локально

Запустите npm run build:css-examples, затем откройте этот файл в браузере. Все стили ниже берутся из локальных файлов — CDN нет.

  • Исходник Sass: BEM, @use и mixin → скомпилированный CSS
  • Вход PostCSS: display: flex и user-select → CSS с префиксами Safari 8
  • Вход Tailwind v4 → сгенерированные utility-классы
  • Скопированный локально Bootstrap CSS
