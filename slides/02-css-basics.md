<!--
CSS — Cascading Style Sheets, каскадные таблицы стилей. Слово *cascading* здесь главное. К одному элементу обычно подходят несколько правил: одно задаёт цвет текста, другое — отступ, третье — состояние при фокусе. Браузер выбирает итоговое значение отдельно для каждого свойства.
-->

```css
.card {
  /* Процент */
  width: 100%;
  /* Длина */
  padding: 20px;
  /* Цвет */
  color: #075985;
  /* Ключевое слово */
  text-decoration: none;
  /* Составное значение */
  border: 1px solid #cbd5e1;
```

<!--
Значения — не произвольные слова. Уже в нашем небольшом примере встречаются пять категорий: ключевое слово `text-decoration: none`; длина `padding: 20px` или `font-size: 2rem`; процент `width: 100%`; цвет `color: #075985`; составное значение `border: 1px solid #cbd5e1`.

Составное значение — это несколько ожидаемых частей для одного свойства: у `border` здесь толщина, вид линии и цвет. Сейчас достаточно узнавать эти формы, а не запоминать каталог единиц и свойств.

Не превращайте слайд в каталог единиц. Эти категории уже встречаются в нашем примере.
-->

items:

  - { term: Пользователь, desc: Пользовательская таблица стилей для собственных потребностей }
  - { term: Автор, desc: "Подключённые CSS-файлы, <code>&lt;style&gt;</code> и атрибут <code>style</code>" }

<!--
У каждого CSS-объявления есть источник, или origin. **Браузер** предоставляет встроенную user-agent stylesheet: благодаря ей заголовок крупнее обычного текста, а ссылка заметна даже без нашего CSS. **Пользователь** может подключить собственную таблицу стилей под свои потребности, например увеличить читаемость интерфейса. **Автор страницы** задаёт правила в подключённых CSS-файлах, элементе `<style>` и атрибуте `style`.

Источник — один из факторов каскада. Обычные авторские объявления обычно переопределяют обычные правила браузера, поэтому наше `h1 { color: #075985; }` меняет базовый вид заголовка. Полный порядок источников и важности здесь не запоминаем: в этой лекции дальше сравниваем обычные авторские объявления, а полный каскад разберём в лекции 5.

В DevTools у одного элемента покажите правило из user-agent stylesheet и правило из `styles.css`. Спросите, кто создал каждое из них.
-->

layout: code-explain
kicker: Авторские стили
title: Три способа подключить CSS
notes:
  - "Внешний файл: <code>&lt;link rel=&quot;stylesheet&quot;&gt;</code> — основной способ"
  - "<code>&lt;style&gt;</code>: правила только для текущего HTML-документа"
  - "Атрибут <code>style</code>: декларации только для одного элемента"
---
```html
<!-- Внешний файл -->
<link rel="stylesheet" href="styles.css">

<!-- Внутри документа -->
<style>
  h1 { color: #075985; }
</style>

<!-- У одного элемента -->
<h1 style="color: #075985;">Заголовок</h1>
```
<!--
Автор страницы может добавить CSS тремя способами.

**Внешняя таблица стилей** подключается в `<head>`. `href` задаёт адрес CSS-файла, а `rel="stylesheet"` сообщает браузеру тип связанного ресурса. Это основной способ для проекта: один файл можно подключить к нескольким страницам, кэшировать и редактировать отдельно от HTML.

**Элемент `<style>`** также обычно размещают в `<head>`, но сами правила находятся внутри HTML-документа. Такие правила действуют только в текущем документе. Способ подходит для небольшого автономного примера, но в проекте смешивает структуру и оформление.

**Атрибут `style`** задаёт декларации непосредственно одному элементу. Здесь нет селектора: элемент уже выбран самим атрибутом. Такое оформление трудно переиспользовать и переопределять, поэтому для обычной вёрстки предпочитаем внешний CSS-файл.

Сопоставьте три примера на слайде: отдельный ресурс, правила текущего документа, декларации одного элемента. Спросите, какой способ позволит использовать одни правила на нескольких страницах.
-->

layout: code-explain
kicker: Другие селекторы
title: Иногда достаточно атрибута или идентификатора
notes:
  - <code>*</code> выбирает все элементы; используйте его осознанно
  - <code>#registration</code> выбирает элемент с уникальным идентификатором
  - <code>input[required]</code> выбирает элементы с указанным атрибутом
---
```css
* {
  box-sizing: border-box;
}

#registration {
  scroll-margin-top: 2rem;
}

input[required] {
  border-color: #075985;
}
```
<!--
Кроме селектора элемента и класса, полезно знать три простых случая: `*` — универсальный селектор, `#registration` — селектор идентификатора, `input[required]` — атрибутный селектор. Универсальный селектор применяем осознанно, а идентификатор сохраняем уникальным.

Универсальный, ID- и атрибутный селекторы полезны, но не заменяют семантическую структуру HTML.
-->
